# Socket.IO: API и эксплуатация

Требуются PHP 8.1+ и Localzet Server `^7.0`. `SocketIO` предоставляет `attach`, `of`, `nsp`, `socket`, `adapter` и настройку origins. Namespace и socket поддерживают события, `emit`/`send` и комнаты через `join`, `leave`, `to`, `in`. Проверяйте входные данные в обработчиках приложения.

Адаптер по умолчанию хранит комнаты в одном процессе; workers не разделяют состояние. `ChannelAdapter` требует совместимый Tunnel — сверяйте ограничения обеих версий в Composer lock. По умолчанию origins разрешены через `*:*`; задайте допустимые источники явно перед подключением недоверенных клиентов. Регрессионные тесты не подтверждают полную работу современных Socket.IO клиентов, long polling, reconnect и межпроцессную доставку. Проверьте handshake, upgrade, origins, комнаты и остановку на фактических версиях.
