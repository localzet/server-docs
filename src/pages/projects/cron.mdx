# Localzet Cron
[Начало работы](/projects/cron/start) · [API и эксплуатация](/projects/cron/reference)


Cron запускает повторяющиеся задачи через event loop Localzet Server. Текущий код объявляет зависимость `localzet/server:^7.0`; тесты проверяют разбор расписаний и одноразовый таймер на backend Select.

```sh
composer require localzet/cron:^2.0
```

Выпуск [`2.0.0`](https://github.com/localzet/Cron/releases/tag/v2.0.0) рассчитан на Server 7; линия `1.x` относится к Server 4. Планировщик использует PHP callbacks внутри процесса. Для нескольких workers задача может выполняться каждым процессом; координацию и защиту от повторного запуска следует обеспечить приложению.
