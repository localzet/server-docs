# SOCKS5: начало работы

SOCKS5 здесь поставляется как самостоятельный сервисный проект, а не пакет для встраивания. Требуются PHP 8.2+, Composer и Linux CLI. Получите исходники, установите зависимости и задайте credentials до запуска:

```sh
git clone https://github.com/localzet/SOCKS5.git
cd SOCKS5
composer install --no-dev --prefer-dist

export SOCKS5_BIND=127.0.0.1
export SOCKS5_PORT=1080
export SOCKS5_USERNAME='proxy-user'
read -rsp 'SOCKS5 password: ' SOCKS5_PASSWORD; export SOCKS5_PASSWORD; echo
php start.php start -d
```

Пароль не записывается в исходники. Для службы задайте переменные через защищённый механизм управления секретами; daemon mode выше подходит только для локальной проверки и ручного управления.

Проверьте локальный TCP CONNECT, запустив включённый сценарий интеграции:

```sh
python3 tests/integration.py
php start.php status
php start.php stop
```

Для ручной проверки используйте клиент, который запрашивает пароль интерактивно; не помещайте credentials в URL или аргументы команды. Логин/пароль SOCKS передаются открытым текстом; внешний доступ прокладывайте через доверенную сеть или защищённый туннель. Сервер по умолчанию слушает loopback и требует аутентификацию. Сверьте поддерживаемые команды и ограничения в [API и эксплуатации](/projects/socks5/reference).
