# Установка Cluster

Cluster пока не зарегистрирован в Packagist. После публикации тега `v1.0.0` подключите Git-репозиторий и установите Cluster:

```sh
composer config repositories.localzet-cluster vcs https://github.com/localzet/Cluster
composer require localzet/cluster:^1.0
```

Cluster 1.x поддерживает Localzet Server `^7.0`. Проверьте итоговую версию в `composer.lock` перед развёртыванием.

Создайте сильный случайный общий секрет и передайте его всем узлам через защищённую конфигурацию. Не помещайте секрет в репозиторий, командную историю, образ контейнера или публичные логи.
