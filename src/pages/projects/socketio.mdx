# Localzet Socket.IO
[Начало работы](/projects/socketio/start) · [API и эксплуатация](/projects/socketio/reference)

Socket.IO [`2.0.3`](https://github.com/localzet/SocketIO/releases/tag/v2.0.3) — актуальный выпуск для Localzet Server 7. Пакет ещё не зарегистрирован в Packagist; подключите Git VCS source и установите стабильную версию:

```sh
composer config repositories.localzet-socketio vcs https://github.com/localzet/SocketIO
composer require localzet/socketio:^2.0
```

В выпуске 2.0.3 `ChannelAdapter` совместим с Tunnel 4.x. Подписка межпроцессной комнаты остаётся активной, пока в ней есть локальные сокеты. Для broadcast между workers установите совместимый Tunnel отдельно: `composer require localzet/tunnel:^4.0`.


SocketIO подключает Engine.IO/Socket.IO обработчики к Localzet Server и содержит собственные WebSocket framing/parser реализации. Для Server 7 добавлен `ProtocolInterface` adapter и схема `socketio://`.

Адаптер по умолчанию хранит состояние в памяти worker и работает без Tunnel. `ChannelAdapter` работает с Tunnel `4.x`. Сквозной тест запускает Tunnel broker и два независимых процесса Socket.IO, затем проверяет доставку broadcast между ними. Тест не покрывает отказ брокера, reconnect, persistence или доставку во время сетевого сбоя.
