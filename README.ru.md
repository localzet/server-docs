# Документация Localzet Server

[English](README.md)

Исходники сайта Next.js/MDX: https://server.localzet.com. Код библиотеки: [localzet/Server](https://github.com/localzet/Server).

## Разработка

Проверенное окружение — Node.js 22 и npm. Используйте закоммиченный npm lock-файл:

```sh
npm ci
npm run dev
npm run lint
npm run build
```

Dev-сайт открывается на http://localhost:3000. Результат сборки — `out/`. Postbuild генерирует sitemap и копирует его в статический экспорт. Сборка не публикует сайт.

## Границы документации

Справочник Server описывает актуальный стабильный выпуск 7.2.2. Переключатель проектов открывает отдельную документацию Cluster, Cron, HTTP Client, MQTT, PSR-7, Proxy, SOCKS5, Socket.IO, Storage, Tunnel, Noter и Triangle Media. Для каждого проекта выделены собственная боковая навигация, поиск, метаданные и сведения о совместимости. Документация Media разделяет опубликованную v1.1.0 для Engine 8 и подготовку ещё не опубликованной версии 2.0.0 для Engine 9.

Старые страницы остаются в архиве, помечены предупреждением и исключены из поиска и sitemap. Справочник Server преимущественно русскоязычный; часть руководств связанных проектов доступна на русском и английском. Документация отражает проверенные исходники и статус релизов, но не заявляет production-готовность или поведение, не подтверждённое проверками.

## Структура

- `src/pages`: MDX-контент и маршруты.
- `src/components`: навигация, поиск и шаблоны страниц.
- `src/mdx`: преобразования MDX и локальный поисковый индекс.
- `public`: статические файлы.
- `scripts/generate-sitemap.js`: генератор sitemap.

CI собирает сайт и выполняет lint при push и pull request. GitHub Pages автоматически публикуется после push в `main`; pull request проверяет сборку, но не разворачивается. Workflow можно также запустить вручную. Успешная статическая сборка не проверяет runtime-поведение библиотеки Server; аудит зависимостей — отдельная проверка.
