# Noter
[Начало работы](/projects/noter/start) · [API и эксплуатация](/projects/noter/reference)


Noter — PHP CLI-проект для создания и управления заметками; в README описана серверная часть и пример интеграции с приложением. Он зависит от `localzet/http:^2.0`; текущий Composer lock разрешает `localzet/http 2.0.2` вместе с `localzet/server 4.5.3`. Не переносите проект на Server 7, пока совместимый выпуск HttpClient не доступен в зависимостях Noter.

```sh
composer install
```

Точные команды, конфигурацию хранилища и режим публикации сверяйте с README и исходниками текущего checkout. Эта страница фиксирует связь с Localzet Server, а не заменяет эксплуатационную инструкцию самого приложения.
