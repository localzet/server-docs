# Совместимость Cluster и Server

## Поддерживаемая связка

Стабильный выпуск [Cluster 1.0.0](https://github.com/localzet/Cluster/releases/tag/v1.0.0) рассчитан на PHP 8.2+ и Localzet Server `^7.0`. Исторические исходники до 1.0.0 относятся к прежней связке и требуют отдельной проверки перед обновлением.

| Версия Cluster | Localzet Server | Статус |
| --- | --- | --- |
| `v1.0.0` и далее | `^7.0` | Server 7 |
| Исторические исходники до 1.0.0 | `^4.2` | Архив; обновление на Server 7 требует пересборки приложения и проверки wire protocol |

Переход с прежней связки меняет runtime Server. Перед обновлением проверьте lifecycle Gateway/Business, регистрацию, межпроцессный wire protocol, callbacks и команды управления процессами.

| Область | Cluster 1.x на Server 7 | Проверка перед production |
| --- | --- | --- |
| Runtime API | Server `^7.0` | Проверить callbacks на целевой версии PHP |
| Транспорт | Gateway/Business и Register | Проверить wire format всех узлов до общего обновления |
| Аутентификация | Общий секрет узлов | Передавать секрет через защищённую конфигурацию; шифровать межузловой канал отдельно |
| Эксплуатация | Многопроцессный Unix runtime | Проверить остановку, reload и восстановление на реальной инфраструктуре |

Не подключайте к одному кластеру узлы с разными основными версиями Server или Cluster без отдельной проверки совместимости протокола.
