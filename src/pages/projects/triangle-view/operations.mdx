# Конфигурация и безопасность

## Handler и параметры

`config/view.php` по умолчанию выбирает `raw`. Переменная окружения `VIEW_HANDLER` может выбрать `raw`, `blade`, `twig` или `think`. Сторонний движок устанавливается отдельно: `jenssegers/blade`, `twig/twig` либо `topthink/think-template`. Пакет помечает эти зависимости как optional suggestions.

Основные параметры:

```php
return [
    'handler' => Triangle\View\Render\Raw::class,
    'options' => [
        'view_suffix' => 'phtml',
        'vars' => [],
    ],
];
```

Для приложений и плагинов Engine handler читается из их конфигурационного namespace. Если конфиг уже существует, install helper не перезаписывает его; обновление настроек выполняйте явно.

## Экранирование и доверие

Raw templates исполняются как PHP-код и не экранируют вывод автоматически. Для HTML-контекста экранируйте недоверенные строки через `htmlspecialchars($value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8')`. Для JavaScript, URL и CSS нужны правила экранирования соответствующего контекста; HTML-экранирования недостаточно для всех контекстов.

Не используйте содержимое пользовательского ввода как имя шаблона или PHP-код. Доступ к шаблонам — часть границы доверия приложения. Не размещайте секреты как переменные представления без необходимости: шаблон может вывести их в ответ.

## Ограничения

View формирует тело и статус ответа, но не заменяет контроллер, авторизацию, CSRF-защиту или правила кэширования приложения. Путь шаблона и необязательные движки зависят от конфигурации конкретного проекта.
