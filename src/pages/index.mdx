# Localzet Server

Документация к текущей ветке разработки **7.x**. Localzet Server — библиотека PHP для серверных приложений с долгоживущими соединениями, несколькими сетевыми протоколами и управлением worker-процессами.

Сначала важное о версиях: опубликованные пакеты **4.x** и текущая ветка **7.x** — разные линии совместимости. `composer require localzet/server` выбирает стабильный опубликованный релиз; примеры этой документации относятся к исходникам 7.x. Перед использованием сверяйте версию из `composer show localzet/server` и [таблицу совместимости](/current/compatibility).

## Границы реализации

Сервер реализует HTTP/1.x, TLS поверх PHP streams, WebSocket, TCP и UDP. Gateway включает raw TCP proxy и потоковый HTTP/1.x reverse proxy с WebSocket Upgrade. Он не является HTTP/2/3 ingress, API management платформой или системой service discovery. В проекте нет встроенной аутентификации приложения, rate limiter или гарантии производительности для произвольной нагрузки.

Остальные страницы старого справочника описывают прежние версии API и помечены как архивные. Для актуального кода начинайте с раздела **Линия 7.x** в меню.
