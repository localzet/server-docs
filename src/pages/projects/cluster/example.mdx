# Сценарий использования

Минимальный сценарий использует один Registry, один Gateway и один Business процесс на доверенном loopback окружении. Настройте общий секрет через переменную среды, подключите клиентский транспорт и зарегистрируйте обработчики событий приложения.

Для нескольких машин задайте достижимые приватные адреса, firewall правила для служебных портов и одинаковую секретную конфигурацию. Не используйте пример как публичный edge proxy: Cluster не предоставляет универсальную аутентификацию конечных приложений или шифрование внутреннего трафика.
