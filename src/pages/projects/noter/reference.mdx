# Noter: API и эксплуатация

Noter — CLI отправитель заметок, а не приложение-хранилище. В версии [`v0.1.10`](https://github.com/localzet/Noter/releases/tag/v0.1.10) требуются PHP 8.4.1+ и `ext-curl`. Команда `noter <text>` берёт текст из аргумента; при отсутствии аргумента читает stdin.

## Контракт приёмника

CLI выполняет HTTP POST на `NOTER_URL` и отправляет:

| Часть запроса | Значение |
| --- | --- |
| Content-Type | `application/json` |
| Заголовок авторизации приложения | `X-API-KEY: <NOTER_KEY>` |
| JSON body | `{"content":"..."}` |

Поле `content` содержит исходный текст заметки: Noter не преобразует HTML-символы перед JSON-кодированием. Приёмник обязан сравнить ключ безопасным способом, ограничить размер body, проверить UTF-8/формат и сохранить данные. Перед выводом в HTML кодируйте текст для конкретного контекста; не возвращайте заметку как доверенный HTML.

## Конфигурация и результаты

Установщик сохраняет `NOTER_URL` и `NOTER_KEY` в `/usr/local/noter/noter.zconf`, каталог с правами `0700`, файл с `0600`. CLI сначала ищет `noter.zconf` в `BASE_PATH` установленного приложения/сборки, затем использует `/usr/local/noter/noter.zconf`. Удалённые URL должны использовать HTTPS. URL допускает только HTTP(S); connect timeout — 5 секунд, общий timeout — 20 секунд. Выходной код успешен только для HTTP 2xx. При транспортной ошибке сообщение не включает URL/ключ; HTTP status выводится в терминал.

Передача `-k` при установке может раскрыть ключ через shell history и список процессов. Предпочитайте скрытый интерактивный prompt или защищённый конфигурационный менеджер; не помещайте секреты в README, аргументы, CI logs и issue reports.

## Зависимости и release

Lockfile версии `v0.1.10` фиксирует `localzet/http 3.0.0`, `localzet/psr7 4.0.0`, `localzet/console 2.2.0`, `illuminate/console 13.43.0`, `symfony/console 8.1.11` и `localzet/server 7.1.0`. CI проверяет Composer manifest/lock, lint, PHAR и loopback HTTP сценарии. GitHub Release прикладывает self-contained `noter.phar`; для запуска требуется PHP CLI 8.4.1+ с cURL.
