# Localzet Socket.IO
[Начало работы](/projects/socketio/start) · [API и эксплуатация](/projects/socketio/reference)

Пакет пока не опубликован в Packagist. Подключите Git VCS repository и устанавливайте текущую ветку `dev-main`.

```sh
composer config repositories.localzet-socketio vcs https://github.com/localzet/SocketIO
composer require localzet/socketio:dev-main
```


SocketIO подключает Engine.IO/Socket.IO обработчики к Localzet Server и содержит собственные WebSocket framing/parser реализации. Для Server 7 добавлен `ProtocolInterface` adapter и схема `socketio://`.

Адаптер по умолчанию хранит состояние в памяти worker и работает без Tunnel. Для межпроцессной доставки предусмотрен Tunnel `3.x`, совместимый с Server 7, однако его интеграция с Socket.IO пока не прошла сквозную проверку. Не используйте межпроцессный адаптер в production до подтверждения доставки между независимыми процессами.
