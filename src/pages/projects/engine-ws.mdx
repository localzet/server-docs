# Triangle Engine WS

Engine WS связывает WebSocket transport Localzet Server с приложениями Triangle. Адаптер сопоставляет HTTP upgrade-запрос с маршрутом, запускает middleware проверки handshake, а затем вызывает обработчик маршрута при поступлении frame.

Server отвечает за listener, WebSocket framing, event loop и жизненный цикл worker-процессов. Engine предоставляет типы приложения и Fiber-контекст. Engine WS добавляет callback-и, контекст запроса и методы отправки сообщений.

## Актуальная версия

Текущий опубликованный выпуск — **2.0.0**. Он рассчитан на PHP 8.1+, Engine 9, Router 2, Middleware 2 и Localzet Server 7.1+.

~~~sh
composer require localzet/server:^7.1 triangle/engine-ws:^2.0
composer show triangle/engine-ws
composer show triangle/engine
composer show localzet/server
composer check-platform-reqs
~~~

Версия 1.x относится к предыдущей совместимости Engine 8 / Server 4. Полное сравнение находится в [руководстве по совместимости](/projects/engine-ws/compatibility). Engine WS и Engine HTTP нельзя устанавливать в одном Composer-проекте.

## Ограничения

Карта подключений и группы хранятся в памяти процесса и не синхронизируются между worker-ами или узлами. Для межпроцессной рассылки используйте отдельный broker или IPC-компонент. Engine WS не реализует распределённые комнаты, durable delivery или готовую систему аутентификации.
