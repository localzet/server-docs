# Cron: API и эксплуатация

PHP 8.1+ и Localzet Server `^7.0`. `Cron($rule, $callback, $name = '')` регистрирует задание. `getRule()`, `getCallback()`, `getName()`, `getId()`, `destroy()`, `getAll()` и `remove($id)` позволяют получить параметры и удалить его. У `CronParser` есть методы `isValid()` и `parse()`.

Пять полей задают минуту, час, день месяца, месяц и день недели; шестое добавляет секунды. Задание, зарегистрированное каждым worker, сработает в каждом процессе. Для однократного глобального запуска используйте один процесс-планировщик или распределённую блокировку. Callback работает в event loop, поэтому блокирующую работу передавайте в очередь. Часовые пояса и переходы DST покрыты не полностью. Команды проверки: `composer test`, `composer lint`.
