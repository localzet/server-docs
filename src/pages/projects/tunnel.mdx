# Localzet Tunnel
[Начало работы](/projects/tunnel/start) · [API и эксплуатация](/projects/tunnel/reference)


Tunnel переносит события по именованным каналам и поддерживает очереди сообщений. Текущий выпуск требует Localzet Server 7. Клиент может использовать JSON или совместимый сериализованный wire format.

Десериализация объектов на входе отключена по умолчанию. Статический opt-in `Client::allowObjectSerialization()` и аргумент конструктора Server предназначены только для доверенных peer в изолированной сети.

Протокол не включает аутентификацию транспортного peer. Ограничьте сетевой доступ внешними ACL и оцените доставку, reconnect, очереди, лимиты памяти и shutdown в целевом развёртывании.
