# Localzet MQTT
[Начало работы](/projects/mqtt/start) · [API и эксплуатация](/projects/mqtt/reference)

Пакет пока не опубликован в Packagist. Подключите Git VCS repository и устанавливайте текущую ветку `dev-main`.

```sh
composer config repositories.localzet-mqtt vcs https://github.com/localzet/MQTT
composer require localzet/mqtt:dev-main
```


Пакет `localzet/mqtt` предоставляет экспериментальный клиент MQTT 3.1.1 и MQTT 5 для Localzet Server 7. Composer PSR-4, namespaces и runtime API приведены к текущему контракту Server. Адаптеры протокола подключают клиент к `AsyncTcpConnection`; адреса `mqtt://` и `mqtts://` преобразуются в TCP-соединение с нужным транспортом и портом по умолчанию.

Регрессионный набор проверяет framing неполных и объединённых пакетов, ping-кодирование и выбор MQTT 3/5 адаптера. Интеграционный набор запускает временный Mosquitto и проверяет логин/пароль, доставку и подтверждение QoS 1 для обоих уровней протокола по TCP и TLS, а также переподключение после перезапуска брокера и восстановление подписки.

Тестовый TLS-брокер использует самоподписанный сертификат с отключённой проверкой сертификата на клиенте: тест подтверждает TLS handshake, но не валидацию доверенной цепочки сертификатов.

Зависимость: `localzet/server:^7.0`. Лицензия проекта: AGPL-3.0-or-later.
