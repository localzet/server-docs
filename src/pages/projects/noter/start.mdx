# Noter: начало работы

## Установка и запуск

Установщик проекта принимает URL приёмника и API key и создаёт конфигурацию `/usr/local/noter/noter.zconf`. Перед запуском установщика из сети проверьте его содержимое и источник. Не передавайте реальный ключ аргументом в общей shell-сессии: он может сохраниться в истории команд или списке процессов.

## Первый сценарий

```sh
noter "Текст заметки"
printf '%s' "Заметка из stdin" | noter
```

Сверьте совместимость и ограничения в разделе API и эксплуатации до включения в приложение.
