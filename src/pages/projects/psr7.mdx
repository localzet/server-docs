# Localzet PSR-7
[Начало работы](/projects/psr7/start) · [API и эксплуатация](/projects/psr7/reference)


Релиз `4.0.0` предоставляет HTTP message и stream реализации, URI helpers и адаптер server request; пакет требует PHP 8.2+, `psr/http-message:^2.0` и `localzet/server:^7.0`.

```sh
composer require localzet/psr7:^4.0
```

Линия `4.x` предназначена для Server 7; историческая линия `3.x` рассчитана на Server 4. Установка `^4.0` фиксирует совместимую основную версию; перед обновлением проверьте поведение потоков и URI в приложении.

Установка и автозагрузка сами по себе не подтверждают PSR-7 conformance. Проверяйте неизменяемость сообщений, потоки, URI encoding, multipart uploads и совместимость с потребителем.
