# Установка Triangle Web

Triangle Web опубликован как Composer project `v8.0.1`. Requirements этого релиза: PHP `^8.2`, `ext-curl`, `ext-json`, Engine `^8.1`, Engine HTTP `^2.0`, Console `^1.3`, Database `^1.0`, Session `^1.0`, View `^2.0`, Events `^1.0`.

```sh
composer create-project triangle/web:^8.0 my-web-app
cd my-web-app
composer show triangle/web triangle/engine triangle/engine-http triangle/console triangle/database triangle/session triangle/view triangle/events
```

Проверьте `composer.lock` и PHP extensions. Ограничение Engine `^8.1` не принимает Engine 9. Точка входа проекта — `master`: она загружает autoload, задаёт пути, читает `.env`, запускает Engine autoloader и Console. Перед запуском подготовьте рабочие `.env`, каталоги `public` и `runtime`; не храните секреты в git.
