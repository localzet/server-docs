# Proxy: начало работы

## Установка

```sh
composer require localzet/proxy
```

## Первый сценарий

```php
use localzet\Proxy;

$proxy = new Proxy('tcp://127.0.0.1:8080');
$proxy->count = 1;
$proxy->allowedHosts = ['api.example.org'];
$proxy->allowedPorts = [80, 443];
Proxy::runAll();
```

Сверьте совместимость и ограничения в разделе API и эксплуатации до включения в приложение.
