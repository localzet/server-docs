# Localzet Cron

Cron запускает повторяющиеся задачи через event loop Localzet Server. Текущий код объявляет зависимость `localzet/server:^7.0`; тесты проверяют разбор расписаний и одноразовый таймер на backend Select.

```sh
composer require localzet/cron
```

Планировщик использует PHP callbacks внутри процесса. Для нескольких workers задача может выполняться каждым процессом; координацию и защиту от повторного запуска следует обеспечить приложению.
