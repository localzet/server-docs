# Localzet HTTP Client
[Начало работы](/projects/httpclient/start) · [API и эксплуатация](/projects/httpclient/reference)


HttpClient выполняет HTTP-запросы из event loop Localzet Server и предоставляет connection pooling. Релиз `3.0.0` требует Server `^7.0`, PHP 8.2+ и расширения cURL/JSON.

```sh
composer require localzet/http:^3.0
```

Релиз `3.0.0` рассчитан на Server 7, PHP 8.2+, PSR-7 4 и `ext-curl`. Историческая линия `2.x` относится к Server 4. Перед эксплуатацией проверьте TLS, редиректы, таймауты, ошибки и закрытие соединений в целевом приложении.
