# Localzet Storage

Storage предоставляет клиент-серверное общее in-memory хранилище. Пакет требует PHP 8.2+ и Localzet Server 7. По умолчанию listener привязан к `127.0.0.1:8008`; встроенной аутентификации нет.

Сетевой формат совместим с PHP serialization, но десериализация объектов выключена. Opt-in `allowObjectSerialization: true` на обеих сторонах допустим только в доверенной изолированной сети. Значения хранятся в памяти процесса и не обеспечивают персистентность или репликацию.

Перед внешней сетевой привязкой настройте ACL; проверяйте размеры фреймов, доступность сервиса и операции конкурентных клиентов.
