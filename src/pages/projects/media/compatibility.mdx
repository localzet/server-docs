# Совместимость и переход

Опубликованный тег `v1.1.0` требует `triangle/engine:^8.1`. Подготавливаемый следующий major `2.0.0` требует `triangle/engine:^9.0` и предназначен для Engine 9 с Localzet Server 7. PHP-минимум остаётся 8.1. Эти major-версии нельзя смешивать в одном Composer dependency graph.

Релиз `2.0.0` ещё не опубликован. Сравните фактические версии в lock-файле и статус [репозитория](https://github.com/Triangle-org/Media).

## Что меняется для приложения

| Область | Старый интеграционный контракт | Engine 9 |
| --- | --- | --- |
| Composer | Пакет зависел от Engine 8 | Зависимость обновлена до `triangle/engine:^9.0`; старый пакет нельзя смешивать с этой веткой в одном lock-файле. |
| Multipart-файл | Контроллер ожидал legacy upload object и обращался к глобальному запросу | Engine возвращает `Triangle\Engine\File`; контроллер проверяет тип, статус загрузки и имя файла из текущего `Request`. |
| Поля и токен | Читались из глобального запроса | Токен, файл и ссылка берутся из внедрённого объекта запроса. |
| IP клиента | Использовался внешний helper приложения | Используется `Request::getRequestIp()`; forwarding-заголовки учитываются только от доверенного proxy. |
| Регистрация проекта | В шаблонной конфигурации была включена | Для новых установок выключена (`project_registration = false`). |
| ImageMagick | Фильтры не ограничивали число выходных пикселей | Добавлены лимиты кадров, суммарных пикселей и ресурсов обработки. |

## Порядок перехода

1. Убедитесь, что приложение уже работает на Engine 9 и совместимой версии Server 7.
2. Обновите зависимости в отдельной ветке и проверьте итоговый `composer.lock`.
3. Проверьте middleware и proxy: только реальные доверенные узлы должны передавать клиентский IP в forwarded-заголовках.
4. Сверьте установленную конфигурацию `project_registration`. `Install::install()` не перезаписывает существующие настройки, поэтому старое значение `true` сохранится после обновления.
5. Подключите Engine database/storage adapters и тестовые представления, затем выполните интеграционные запросы приложения.

Не переносите вслепую версии Engine, Server и Media между старыми и новыми ветками. Используйте Composer lock-файл приложения как фактический источник разрешённых версий.
