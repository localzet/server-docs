# Безопасность и эксплуатация

## Проверка пути

Адаптер проверяет URI до маршрутизации и повторно проверяет путь после percent-decoding. Небезопасный путь передаётся fallback-у со статусом 422. Эта проверка на уровне маршрутизации не заменяет изоляцию файловой системы и права процесса.

Статические файлы разрешаются внутри вычисленного public-пути приложения или plugin-а. Не размещайте секреты, конфигурацию и служебные файлы внутри доступного каталога.

## Выполнение PHP

Выполнение PHP-файлов из public-пути выключено по умолчанию. Не включайте app.support_php_files для пользовательского содержимого. Если такое выполнение необходимо, ограничьте источник и права на каталог.

## Заголовки и доступ

Проверьте фактические CORS-заголовки, доверенные proxy и TLS-настройки в приложении и Server. Наличие адаптера не означает, что аутентификация, TLS или proxy уже настроены. Ограничьте origin, методы и заголовки конкретным сценарием.

## Эксплуатация

Лимиты соединений и размеров запросов, таймауты и graceful shutdown настраиваются в Server. Используйте разные конфигурации для тестового и production окружений. Не записывайте токены и персональные данные в логи без обоснованной политики хранения.
