# Совместимость Cluster и Server

## Текущий выпуск

Cluster в этой документации соответствует исходникам репозитория Cluster и зависит от `localzet/server:^4.2`. Примеры и API ниже относятся к этой связке.

## Server 7

Совместимость Cluster с Server 7 не заявлена. Server 7 изменил модель протоколов и событийный runtime; обновление одной зависимости не является миграцией. Порт требует проверки lifecycle Gateway/Business, регистрации, межпроцессного wire protocol, callbacks и управления процессами.

| Область | Выпуск Cluster | Что потребуется для Server 7 |
| --- | --- | --- |
| Runtime API | Server `^4.2` | Перенести и проверить серверные callbacks и lifecycle |
| Транспорт | Gateway/Business и Register | Сохранить wire format и проверить старых клиентов |
| Аутентификация | Общий секрет узлов | Повторно проверить порядок handshake и отказов |
| Эксплуатация | Многопроцессный Unix runtime | Проверить остановку, reload и восстановление |

До отдельного интеграционного выпуска не меняйте ограничение зависимости Cluster на Server 7.
