# Localzet Server

Документация к текущей версии разработки **7.x**. Localzet Server — библиотека PHP для серверных приложений с долгоживущими соединениями, несколькими сетевыми протоколами и управлением worker-процессами.

Установленный через Composer пакет и текущая версия исходников могут различаться. Примеры здесь относятся к коду в репозитории. Перед использованием проверьте версию командой `composer show localzet/server`; подробное сравнение версий и изменений приведено в [совместимости](/current/compatibility).

## Границы реализации

Сервер реализует HTTP/1.x, TLS поверх PHP streams, WebSocket, TCP и UDP. Gateway включает raw TCP proxy и потоковый HTTP/1.x reverse proxy с WebSocket Upgrade. Он не является HTTP/2/3 ingress, API management платформой или системой service discovery. В проекте нет встроенной аутентификации приложения, rate limiter или гарантии производительности для произвольной нагрузки.

Справочные страницы, которые не входят в текущую документацию, помечены как архивные. Для актуального кода начинайте с раздела **Текущая версия · 7.x** в меню.
