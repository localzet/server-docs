# Запуск и остановка Cluster

В репозитории Cluster находится пример конфигурации из нескольких процессов. Скопируйте его в приложение, укажите адреса Registry/Gateway и один общий секрет из окружения. Из [инструкции установки](/projects/cluster/install) возьмите безопасный способ передачи секрета.

```sh
php start.php start
php start.php status
php start.php reload
php start.php stop
```

Сначала запускайте Registry, затем Gateway и Business процессы в порядке, принятом вашим entry point. Команды и имена файлов сверяйте с текущей конфигурацией приложения: демонстрационные файлы репозитория не являются готовой production-конфигурацией.
