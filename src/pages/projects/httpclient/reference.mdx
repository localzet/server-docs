# HTTP Client: API и эксплуатация

Ветка исходников требует PHP 8.0+, расширения `curl` и `json`, Localzet Server `^7.0` и PSR-7 `^3.0`. Методы `get()`, `post()` и `request()` асинхронны: результат доступен в callback успеха, ошибка — в callback ошибки. `request()` принимает HTTP-версию и callbacks в массиве параметров. `ParallelClient` добавляет `push()`, `batch()` и `await()`; формат набора запросов сверяйте с кодом установленной версии. Стабильный тег `v2.0.2` относится к Server 4.2, не к этой ветке.

Ограничивайте число соединений и задавайте таймауты. Обрабатывайте оба callback, не пишите секретные заголовки в журнал и проверяйте TLS. Redirect, отмена, потоковая передача и закрытие пула требуют интеграционных проверок. В манифесте нет именованных команд тестирования и lint.
