# HTTP Client: начало работы

## Установка

```sh
composer require localzet/http:dev-main
```

Ветка `dev-main` соответствует Server 7. Последний стабильный тег `v2.0.2` требует Server 4.2; версии пакета и исходников нельзя считать взаимозаменяемыми.

## Первый сценарий

```php
use localzet\HTTP\Client;

$http = new Client([
    'max_conn_per_addr' => 32,
    'keepalive_timeout' => 15,
    'connect_timeout' => 10,
    'timeout' => 20,
]);
$http->get('https://example.com/status',
    success: static function ($response): void {
        echo $response->getStatusCode();
    },
    error: static function ($exception): void {
        error_log((string) $exception);
    }
);
```

Сверьте совместимость и ограничения в разделе API и эксплуатации до включения в приложение.
