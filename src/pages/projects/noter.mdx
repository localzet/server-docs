# Noter
[Начало работы](/projects/noter/start) · [API и эксплуатация](/projects/noter/reference)


Noter — PHP CLI-проект для отправки заметок на HTTP(S)-приёмник. Выпуск `v0.1.7` требует PHP 8.4.1+ и cURL, использует `localzet/http:^3.0`, `localzet/psr7:^4.0` и `localzet/console:^2.0`. Lockfile фиксирует Localzet Server 7. Бинарная сборка и установка описаны ниже; исходники и журнал версий доступны в [репозитории Noter](https://github.com/localzet/Noter).

```sh
composer install
```

Точные команды, конфигурацию хранилища и режим публикации сверяйте с README и исходниками текущего checkout. Эта страница фиксирует связь с Localzet Server, а не заменяет эксплуатационную инструкцию самого приложения.
