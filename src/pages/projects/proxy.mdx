# Localzet Proxy
[Начало работы](/projects/proxy/start) · [API и эксплуатация](/projects/proxy/reference)

Proxy `1.0.0` — выпуск для Localzet Server 7 с обязательной Basic-аутентификацией и allowlist адресов назначения. Пакет ещё не зарегистрирован в Packagist; подключите Git VCS source и установите стабильный tag:

```sh
composer config repositories.localzet-proxy vcs https://github.com/localzet/Proxy
composer require localzet/proxy:^1.0
```


HTTP forward proxy на Localzet Server 7. Каждый запрос требует `Proxy-Authorization: Basic`; исходящие TCP-подключения ограничены `allowedHosts` и `allowedPorts`. Разрешайте только буквальные IPv4/IPv6 адреса: доменные имена отклоняются, чтобы не полагаться на неприкреплённый DNS-результат.

Basic credentials передаются открытым текстом внутри HTTP. Используйте прокси только в доверенной зашифрованной сети или за TLS terminator; сохраните исходящие сетевые ACL как дополнительную границу. Интеграционные проверки покрывают аутентификацию, HTTP, CONNECT, allowlist, некорректный запрос и ошибку upstream. Пакет обрабатывает один запрос на клиентское соединение и не является полнофункциональным HTTP parser.
