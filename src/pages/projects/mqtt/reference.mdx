# Mqtt: API и эксплуатация

Пакет требует Localzet Server `^7.0`. `mqtt://host[:port]` использует порт 1883 по умолчанию, `mqtts://` — 8883. `protocol_level: 4` выбирает MQTT 3.1.1, `5` — MQTT 5. Параметры TLS передаются через `ssl`; оставляйте проверку сертификата включённой. Основные методы: `connect`, `subscribe`, `unsubscribe`, `publish`, `disconnect`, `reconnect`.

`resubscribe` восстанавливает подписки, но не гарантирует однократную обработку сообщения. Делайте handlers идемпотентными и учитывайте QoS и состояние сессии. В репозитории есть тесты протокола и сценарий с Mosquitto. Самоподписанный сертификат в тесте не проверяет production цепочку доверия.
