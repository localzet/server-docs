# Localzet PSR-7
[Getting started](/projects/psr7/en/start) · [API and operations](/projects/psr7/en/reference)

Release `4.0.0` provides HTTP message and stream implementations, URI helpers, and a server request adapter. The package requires PHP 8.2+, `psr/http-message:^2.0`, and `localzet/server:^7.0`.

```sh
composer require localzet/psr7:^4.0
```

Version `4.x` targets Server 7. The `^4.0` constraint selects a compatible major version; verify stream and URI behavior in your application.

Installation and autoloading alone do not establish PSR-7 conformance. Check message immutability, streams, URI encoding, multipart uploads, and compatibility with the consuming package.
