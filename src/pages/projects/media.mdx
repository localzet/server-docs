# Triangle Media

Triangle Media — плагин для приложений на Triangle Engine. Он принимает файлы и публичные HTTP(S)-ссылки, проверяет источник, преобразует изображение, сохраняет метаданные через адаптер приложения и отдаёт результат через маршруты плагина.

Последний опубликованный тег Media — `v1.1.0`; он требует Triangle Engine `^8.1`. Эта документация описывает подготовку следующего основного релиза `2.0.0` для Engine 9 и Server 7. Он пока не опубликован. Сверяйте версию в `composer.lock` и статус [PR репозитория](https://github.com/Triangle-org/Media/pulls).

## Что делает пакет

- Принимает один multipart-файл или ссылку на изображение.
- Проверяет содержимое, допустимый MIME-тип и размер файла.
- Ограничивает число кадров, суммарное число пикселей и ресурсы ImageMagick.
- Преобразует принятые изображения в настроенный формат; по умолчанию это PNG.
- Хранит метаданные через адаптер базы данных приложения.
- Поддерживает `crop`, `resize`, `pixelize` и `cover`.
- Ограничивает загрузку по URL: проверяет адреса DNS, закрепляет публичный IP и не переходит по redirect.

Плагин не заменяет CDN, хранилище объектов, аутентификацию приложения или политику сетевого доступа. Адаптеры базы данных и кэша, а также HTML-шаблоны остаются в приложении.

## Требования

PHP 8.1+, Triangle Engine 9, расширения `curl`, `fileinfo` и `imagick`, доступный для записи каталог изображений и совместимые адаптеры приложения. Подробные требования и контракт адаптеров приведены в [установке](/projects/media/start) и [настройках](/projects/media/configuration).

## Основные маршруты

При стандартном `app.plugin_uri = 'app'` используются следующие пути. Изменение префикса приложения меняет все маршруты.

| Маршрут | Метод | Назначение |
| --- | --- | --- |
| `/app/media` | `GET` | Представление `index`; query-параметр `token` может быть сохранён в cookie на 7 дней. |
| `/app/media/project` | `GET`, `POST` | Регистрация проекта выключена по умолчанию; после включения маршрут показывает форму и создаёт токен. |
| `/app/media/upload` | `POST` | Загрузка файла из поля `file` или ссылка в поле `link`; нужен токен проекта. |
| `/app/media/image/{id}` | `GET` | Представление страницы изображения. |
| `/app/media/processing/{id}/{filter}/{params}` | `GET` | Возвращает байты преобразованного изображения с настроенным MIME-типом. |

Для практических запросов, структуры ответа и управления токеном откройте [инструкцию загрузки](/projects/media/upload).
