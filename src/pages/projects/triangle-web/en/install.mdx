# Install Triangle Web

Triangle Web is published as Composer project `v8.0.1`. Its release requirements are PHP `^8.2`, `ext-curl`, `ext-json`, Engine `^8.1`, Engine HTTP `^2.0`, Console `^1.3`, Database `^1.0`, Session `^1.0`, View `^2.0`, and Events `^1.0`.

```sh
composer create-project triangle/web:^8.0 my-web-app
cd my-web-app
composer show triangle/web triangle/engine triangle/engine-http triangle/console triangle/database triangle/session triangle/view triangle/events
```

Check `composer.lock` and PHP extensions. Engine constraint `^8.1` excludes Engine 9. The project entry point is `master`: it loads autoloading, sets paths, reads `.env`, starts the Engine autoloader, and runs Console. Prepare environment-specific `.env`, `public`, and `runtime` paths before startup; do not commit secrets.
