# Измерение производительности

Ранее опубликованная на этой странице таблица QPS/latency не сопровождалась воспроизводимым набором исходников и конфигурацией, поэтому она удалена. Проект не публикует подтверждённые значения production throughput, максимального числа соединений или сравнение с другими серверами.

## Benchmark в репозитории

`composer benchmark` запускает `tests/benchmark.php`: HTTP `Request` создаётся из фиксированного request buffer, извлекается query-параметр и подсчитываются длительность, операции в секунду и peak memory. JSON включает версию PHP, SAPI, ОС, архитектуру, число итераций и прогрев.

```sh
LOCALZET_BENCH_WARMUP=5000 LOCALZET_BENCH_ITERATIONS=100000 composer benchmark
```

`--smoke` выполняет 100 итераций только для проверки сценария. Это измерение небольшого парсерного пути, не полный socket round-trip.

## Что нужно для прикладного сравнения

Для воспроизводимого сравнения укажите commit, runtime versions, CPU/RAM, kernel, PHP build/extensions, event-loop backend, worker count, TLS/proxy topology, payload mix, concurrency, warm-up, длительность, client tool, p50/p95/p99 latency, ошибки и число завершённых операций. Сохраните скрипт запуска и сырые результаты. Повторите тест на нескольких прогонах.

Показатели одного хоста не переносятся автоматически на другой deployment и не являются обещанием поддержки конкретного уровня нагрузки.
