# Localzet Server

Последняя опубликованная версия Localzet Server — **7.0.2**. Эта документация описывает текущий код Server 7: PHP-библиотеку для серверных приложений с долгоживущими соединениями, несколькими сетевыми протоколами и управлением worker-процессами.

Пакет `localzet/server:^7.0` устанавливается через Composer. Проверяйте фактически выбранную версию командой `composer show localzet/server`; таблица [совместимости](/current/compatibility) описывает требования и изменения при переходе с предыдущих выпусков.

## Границы реализации

Сервер реализует HTTP/1.x, TLS поверх PHP streams, WebSocket, TCP и UDP. Gateway включает raw TCP proxy и потоковый HTTP/1.x reverse proxy с WebSocket Upgrade. Он не является HTTP/2/3 ingress, API management платформой или системой service discovery. В проекте нет встроенной аутентификации приложения, rate limiter или гарантии производительности для произвольной нагрузки.

Справочные страницы, которые не входят в текущую документацию, помечены как архивные. Для актуального кода начинайте с раздела **Текущая версия · 7.x** в меню.
