# Storage: API и эксплуатация

Нужны PHP 8.2+ и Localzet Server `^7.0`. Клиент принимает один адрес или список; ключ направляется по CRC32. Доступны `set`, `get`, `add`, `cas`, `increment`, `delete` и магические свойства. Изменение списка серверов меняет размещение части ключей. Данные только в памяти и теряются при остановке.

Формат использует PHP serialization; десериализация объектов выключена по умолчанию. Включайте `allowObjectSerialization: true` одновременно у сервера и клиента только в изолированной доверенной сети. Нет аутентификации, шифрования, персистентности, репликации, TTL API или лимита памяти. Оставьте listener на loopback либо настройте сетевые ACL.
