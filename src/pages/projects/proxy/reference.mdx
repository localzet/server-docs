# Proxy: API и эксплуатация

Нужны PHP 8.1+ и Localzet Server `^7.0`. `allowedHosts` задаёт точные разрешённые имена (без учёта регистра), `allowedPorts` — порты. Обработчик принимает абсолютные URL `http://` и CONNECT для туннеля; некорректные и запрещённые запросы отклоняются.

Аутентификации клиентов нет. Привязывайте listener к loopback или закрытой сети за ingress ACL. Список имён не фиксирует DNS-ответ и не блокирует частные или link-local адреса, если разрешённое имя указывает на них. Настройте исходящий firewall; отдельно проверьте смену DNS, CONNECT и закрытие ресурсов.
