# Localzet Tunnel
[Начало работы](/projects/tunnel/start) · [API и эксплуатация](/projects/tunnel/reference)


Tunnel [`v4.0.1`](https://github.com/localzet/Tunnel/releases/tag/v4.0.1) переносит события и очереди сообщений между процессами Localzet Server 7. `Client` подключается к серверу каналов; сервер маршрутизирует сообщения активным подписчикам и хранит очереди только в памяти. На один процесс сервера действует общий предел в 10 000 ожидающих сообщений и 32 МиБ ожидающих данных. Debug-логи не содержат тела запросов, сообщений или исходный текст исключений.

```sh
composer require localzet/tunnel:^4.0
```

Версии `3.x` и `4.x` рассчитаны на Server 7; версия `2.x` — на Server 4. В `4.x` изменены ограничения payload: объекты и циклические массивы отклоняются по умолчанию, а очередь ограничена одновременно количеством сообщений и объёмом данных. Перед обновлением проверьте формат сообщений и согласованно обновите приложения и брокер.

Десериализация объектов на входе отключена по умолчанию. Статический opt-in `Client::allowObjectSerialization()` и аргумент конструктора Server предназначены только для доверенных peer в изолированной сети.

Протокол не включает аутентификацию транспортного peer. Debug-логи показывают операции и статусы, но не содержимое запросов и сообщений. Ограничьте сетевой доступ внешними ACL и оцените доставку, reconnect, очереди, лимиты памяти и shutdown в целевом развёртывании.
