# Localzet Proxy
[Начало работы](/projects/proxy/start) · [API и эксплуатация](/projects/proxy/reference)


Экспериментальный HTTP forward proxy на Localzet Server 7. Исходящие TCP-подключения разрешены только к именам и портам из `allowedHosts` и `allowedPorts`. Встроенной аутентификации клиентов нет; DNS-резолвинг и блокировка частных IP для разрешённых имён остаются ответственностью сетевой политики.

**Не публикуйте listener в Интернет.** Используйте только в доверенной сети за внешними ingress/egress ACL. Локальная интеграционная проверка покрывает loopback HTTP, CONNECT, запрет неразрешённого порта, некорректный запрос и ошибку подключения upstream. Она не проверяет клиентскую аутентификацию, DNS rebinding или частные адреса за разрешённым именем; эти ограничения нужно закрыть сетевой политикой.
