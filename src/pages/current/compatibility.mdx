# Совместимость и поддерживаемые возможности

Эта документация описывает исходники ветки 7.x. Она не является справочником для стабильного пакета 4.x.

## Версии

| Линия | Где используется | Как выбирать |
|---|---|---|
| 7.x | Текущий исходный код репозитория и эта документация | Установить исходники ветки `main` для разработки и проверки |
| 4.x | Опубликованный compatibility release, используемый существующими пакетами Localzet | Проверить вывод `composer show localzet/server` и документацию конкретного релиза |

Публичные namespace и сигнатуры могли измениться между линиями. Не обновляйте production-приложение с 4.x до 7.x только заменой constraint: прогоните приложение и его протокольные тесты на целевой версии.

## PHP и операционные системы

- Runtime constraint исходников: PHP `>=8.1`; `ext-json` обязателен.
- Основная CI-матрица проекта выполняется на Linux с PHP 8.1–8.5.
- Windows использует отдельный backend и предназначен для однопроцессного режима; эта платформа не входит в указанную Linux CI-матрицу.
- На Unix supervisor и несколько workers требуют `pcntl` и `posix`. Возможность hot upgrade зависит также от Unix descriptor passing и проверяется runtime-командой `capabilities`.

## Event loop backends

| Backend | Требование | Автоматический выбор |
|---|---|---|
| `select` | Встроенный PHP stream select | Fallback |
| `event` | Расширение `event` и `EventBase` | Unix, если доступно |
| `ev` | Расширение `ev` и `Ev` | Unix, если `event` недоступен |
| `revolt` / `fiber` | Пакет `revolt/event-loop` | Unix, если предыдущие backend-ы недоступны |
| `swoole`, `swow` | Соответствующее расширение/runtime | Только явный выбор |
| `windows` | Windows runtime | Выбирается автоматически в Windows |

Автоматический выбор на Unix имеет порядок `event` → `ev` → Revolt → Select. Явный выбор недоступного backend-а завершается ошибкой, а не незаметным fallback. Проверяйте `php server.php capabilities --json` на целевом окружении.

## Необязательные интеграции

Redis и MongoDB нужны только при выборе соответствующих session handlers. `ext-sockets` применяется отдельными возможностями, включая передачу listening descriptors при поддерживаемом hot upgrade. Не устанавливайте эти зависимости, если приложение не использует их функции.
