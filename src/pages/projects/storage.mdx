# Localzet Storage
[Начало работы](/projects/storage/start) · [API и эксплуатация](/projects/storage/reference)

Storage `2.0.0` — общее in-memory хранилище для процессов приложения на Localzet Server 7 с ограниченным framing и запретом объектов и циклических массивов по умолчанию.

```sh
composer config repositories.localzet-storage vcs https://github.com/localzet/Storage
composer require localzet/storage:^2.0
```

Текущий стабильный выпуск — [`2.0.0`](https://github.com/localzet/Storage/releases/tag/v2.0.0). Он обновляет framing для Server 7, корректно обрабатывает частичные чтения и записи, ограничивает размер фрейма 64 МиБ и по умолчанию принимает только скаляры и ациклические массивы. Репозиторий пока не публикует пакет на Packagist, поэтому Composer подключается напрямую к VCS.


Storage предоставляет клиент-серверное общее in-memory хранилище. Пакет требует PHP 8.2+ и Localzet Server 7. По умолчанию listener привязан к `127.0.0.1:8008`; встроенной аутентификации нет.

Переход с версии 1.x требует согласованно обновить клиент и сервер; удалите объекты и циклические массивы из передаваемых значений либо включайте `allowObjectSerialization: true` на обеих сторонах только в доверенной изолированной сети. Значения хранятся в памяти процесса и не обеспечивают персистентность или репликацию.

Перед внешней сетевой привязкой настройте ACL; проверяйте размеры фреймов, доступность сервиса и операции конкурентных клиентов.
