# Требования Cluster

- PHP 8.2 или новее.
- Composer для установки зависимостей.
- Для многопроцессного режима Unix нужны `pcntl` и `posix`.
- Все узлы кластера должны иметь одинаковый секрет длиной не менее 32 байт.
- Registry и внутренние порты Gateway должны быть доступны между узлами по приватной сети.

Общий секрет аутентифицирует участника, но не шифрует соединение. Используйте защищённую сеть или внешний защищённый транспорт. Рабочие значения портов и адресов зависят от конфигурации вашего приложения.
