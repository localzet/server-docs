# Socket.IO: API и эксплуатация

Пакет требует PHP 8.1+ и Localzet Server `^7.0`. Создайте `SocketIO`, привяжите к серверу через `attach($server, $options = [])` и регистрируйте обработчики до запуска процессов. `of($namespace)` выбирает namespace; `origins($rule)` задаёт разрешённые browser origins.

## События и комнаты

У socket доступны `on($event, $callback)`, `emit($event, ...$data)`, `send()`, `join($room)`, `leave($room)` и `disconnect()`. Namespace/adapter предоставляет рассылку в `to($room)->emit(...)` и `in($room)->emit(...)`. Валидируйте payload, аутентифицируйте handshake в приложении и проверяйте доступ пользователя к каждому room/event.

По умолчанию используется `DefaultAdapter`, который хранит подключения и rooms в памяти worker. Изменение комнаты в одном процессе не синхронизируется автоматически с другими. `ChannelAdapter` использует Tunnel 3.x, совместимый с Server 7, однако сквозная доставка через адаптер пока не подтверждена. Не включайте его в эксплуатацию до прохождения межпроцессного интеграционного теста.

## Совместимость протокола и безопасность

Реализация включает собственные Engine.IO/Socket.IO parsers и WebSocket framing. Текущие регрессии покрывают выбор Server listener и часть RFC6455 framing, но не подтверждают полную совместимость с современными Socket.IO клиентами, long polling, upgrade, binary payload или reconnect. Перед выпуском выполните реальный browser/client handshake, transport upgrade, комнаты, acknowledgements, disconnect и cross-worker сценарий на закреплённой версии клиента.

Origins по умолчанию установлены в `*:*`. Задавайте конкретные origins, но помните: CORS/origin policy не является аутентификацией; проверки кода разрешают запросы без Origin. Привязывайте публичный listener за TLS ingress, проверяйте авторизацию приложения и ограничивайте размер/частоту событий. Не включайте межпроцессную доставку до подтверждения совместимости адаптера.
