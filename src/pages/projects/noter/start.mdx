# Noter: начало работы

## Установка и запуск

Нужны PHP 8.4.1+ и расширение cURL. Скачайте установщик с официального репозитория, проверьте его содержимое и только затем запускайте от root. Укажите URL приёмника; API key вводится скрыто. Конфигурация сохраняется в `/usr/local/noter/noter.zconf` с правами только для root.

```sh
curl -fsSLo /tmp/noter-install.sh --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/localzet/noter/main/install.sh
less /tmp/noter-install.sh
sudo bash /tmp/noter-install.sh -u "https://notes.example.test/save"
```

## Первый сценарий

```sh
noter "Текст заметки"
printf '%s' "Заметка из stdin" | noter
```

Сверьте совместимость и ограничения в разделе API и эксплуатации до включения в приложение.
