# Localzet MQTT
[Начало работы](/projects/mqtt/start) · [API и эксплуатация](/projects/mqtt/reference)

MQTT `1.0.0` — клиент MQTT 3.1.1 и MQTT 5 для Localzet Server 7.

```sh
composer config repositories.localzet-mqtt vcs https://github.com/localzet/MQTT
composer require localzet/mqtt:^1.0
```


Пакет `localzet/mqtt` предоставляет клиент MQTT 3.1.1 и MQTT 5 для Localzet Server 7. Адаптеры протокола подключают клиент к `AsyncTcpConnection`; адреса `mqtt://` и `mqtts://` выбирают TCP и TLS транспорт.

Регрессионный набор проверяет framing неполных и объединённых пакетов, ping-кодирование и выбор MQTT 3/5 адаптера. Интеграционный набор запускает временный Mosquitto и проверяет логин/пароль, QoS 1/2 для обоих уровней протокола по TCP и TLS, а также переподключение после перезапуска брокера и восстановление подписки.

Тестовый TLS-брокер использует самоподписанный сертификат с отключённой проверкой сертификата на клиенте: тест подтверждает TLS handshake, но не валидацию доверенной цепочки сертификатов.

Зависимость: `localzet/server:^7.0`. Лицензия проекта: AGPL-3.0-or-later.
