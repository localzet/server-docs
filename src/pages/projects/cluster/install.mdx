# Установка Cluster

Установите совместимый выпуск пакета:

```sh
composer require localzet/cluster
```

Перед развёртыванием проверьте ограничение `localzet/server` в установленном lock-файле. Текущая ветка Cluster использует Server `^4.2`; Server 7 не входит в это требование.

Создайте сильный случайный общий секрет и передайте его всем узлам через защищённую конфигурацию. Не помещайте секрет в репозиторий, командную историю, образ контейнера или публичные логи.
