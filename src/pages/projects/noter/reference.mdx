# Noter: API и эксплуатация

Настройте `NOTER_URL` и `NOTER_KEY` в `noter.zconf`. Noter отправляет POST с JSON-полем `content` и заголовком `X-API-KEY`; перед отправкой текст HTML-экранируется. Установщик создаёт каталог конфигурации с правами `0700` и файл с правами `0600`; для удалённого приёмника используйте HTTPS.

Приёмник должен проверять ключ, валидировать тип и размер `content`, сохранять заметку и возвращать ответ. CLI читает аргумент или stdin. Noter ограничивает подключение пятью секундами, весь запрос — двадцатью секундами, принимает только HTTP(S) и возвращает ошибочный код при транспортной ошибке или ответе вне диапазона 2xx. Передача ключа через `-k` может оставить его в истории shell и списке процессов; используйте скрытый интерактивный запрос установщика.
