# Noter: API и эксплуатация

Настройте `NOTER_URL` и `NOTER_KEY` в `noter.zconf`. Noter отправляет POST с JSON-полем `content` и заголовком `X-API-KEY`; перед отправкой текст HTML-экранируется. Ограничьте права файла и используйте HTTPS.

Приёмник должен проверять ключ, валидировать тип и размер `content`, сохранять заметку и возвращать ответ. CLI читает аргумент или stdin. При транспортной ошибке cURL утилита завершится с ошибкой, но текущая реализация не считает HTTP 4xx/5xx ошибкой и не задаёт явные сетевые таймауты. Это нужно учитывать при настройке приёмника и повторных запросов.
