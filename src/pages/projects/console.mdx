# Localzet Console

Localzet Console — библиотека для создания PHP CLI-приложений. Она основана на Symfony Console, сохраняет обычный API Symfony по умолчанию и позволяет подключать команды Laravel Artisan к существующему приложению.

Текущая версия — `2.0.1`. Она требует PHP 8.4.1+, Symfony Console 8.1 и Illuminate Console 13. Установка через Composer: `composer require localzet/console:^2.0`.

## Возможности

- Приложение командной строки и автопоиск локальных команд.
- Opt-in регистрация Illuminate-команд с контейнером Laravel.
- UTF-8 ширина текста в терминальных ячейках, безопасное ANSI-обрезание и очистка control sequences.
- Полноэкранный `/dev/tty` renderer для интерактивного режима.
