# Noter
[Начало работы](/projects/noter/start) · [API и эксплуатация](/projects/noter/reference)


Noter — PHP CLI-проект для отправки заметок на HTTP(S)-приёмник. Требуются PHP 8.2+ и cURL. Пакет зависит от `localzet/http:^2.0`; актуальный lock фиксирует `localzet/http 2.0.2` вместе с `localzet/server 4.5.3`. Это отдельная линия совместимости: не подключайте Noter к Server 7 без обновления HTTP-клиента и проверки его API.

```sh
composer install
```

Точные команды, конфигурацию хранилища и режим публикации сверяйте с README и исходниками текущего checkout. Эта страница фиксирует связь с Localzet Server, а не заменяет эксплуатационную инструкцию самого приложения.
